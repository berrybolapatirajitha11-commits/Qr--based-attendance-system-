
# QR-Based Smart Attendance Management System

## Project Overview
The QR-Based Smart Attendance Management System is a web-based application developed using Python and Flask. It helps manage student attendance digitally through QR code scanning.

## Features
- Student registration and management
- Automatic QR code generation
- QR-based attendance marking
- Manual attendance management
- Daily attendance dashboard
- Present, absent, and unmarked student statistics
- Weekly attendance analysis
- Attendance percentage calculation
- CSV attendance report download
- Student deletion

## Technologies Used
- Python
- Flask
- SQLite
- HTML
- CSS
- JavaScript
- Bootstrap
- QR Code

## How It Works
1. Register students with their roll number, name, and class.
2. Generate a unique QR code for an attendance session.
3. Scan the QR code to open the attendance page.
4. Enter the student's roll number.
5. The system verifies the student and marks attendance.
6. View attendance statistics and download reports.
